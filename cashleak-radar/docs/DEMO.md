# 5-minute demo

1. Open the CashLeak Radar landing page.
2. Show the four cash-risk numbers.
3. Open Cash Leak Explorer and select an anomaly.
4. Show the evidence timeline behind the alert.
5. Run the live demo analysis endpoint.
6. Open Recovery Center and show a human-reviewable follow-up draft.

The core story is: **messy evidence → reconciled transaction graph → explainable cash leak → approved recovery action.**
