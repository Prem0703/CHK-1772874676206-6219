# Known limitations

- Persistence is scaffolded but not yet wired through the API.
- OCR provider is an adapter boundary, not a live provider.
- LLM provider is an adapter boundary, not a live provider.
- Demo dashboard values are synthetic.
- Real authentication/RBAC is not yet wired.
- Recovery actions are UI/model level only in this MVP.
- PostgreSQL/Redis are provided for local development.
